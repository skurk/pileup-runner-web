# Pileup-Runner-Web

A web alternative to the fantastic CW training tool &quot;Pileup Runner&quot;.

## Screenshot

![Screenshot](https://github.com/skurk/pileup-runner-web/blob/main/doc/screenshot.png?raw=true)

## Features

- Simple user interface, similar to the original application
- RX frequency can be adjusted in real time
- Realtime adjustable filter width
- Callsigns autogenerated on the fly, any use of existing callsigns are purely coincidental
- Single-page interface, smooth waterfall and audio experience similar to real pileups

## Requirements

Modern web browser (Chrome, Brave, Opera, Edge, or equivalent)

## AI usage

AI was used to create this application.
